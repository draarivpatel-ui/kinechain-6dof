How to use this workbench

Everything on this page is computed locally by the zero-dependency engine in src/robotics.js. No network, no telemetry.

  1. Pick a robot and a preset pose, or drive each joint slider directly.
  2. The two views redraw immediately: side projection (X,Z) and top projection (X,Y).
  3. Set a Cartesian target and run damped least squares inverse kinematics, with optional sphere obstacles.
  4. Plan a quintic pick-and-place trajectory, then export the model as URDF or the run as JSON/CSV.

Keyboard: every control is reachable by Tab, sliders respond to arrow keys, and buttons activate on Space or Enter. Focus rings are always visible.
